## 学到了什么

### 1. 数组创建

```python
np.array([1, 2, 3])          # 从 list 造，一维
np.array([[1,2,3],[4,5,6]])  # 从嵌套 list 造，二维
np.zeros((3, 4))             # 全 0，shape 必须用元组
np.ones((2, 3, 4))           # 全 1，可三维
np.arange(0, 10, 2)          # [0,2,4,6,8]，第 3 个是"步长"，不含 stop
np.linspace(0, 10, 5)        # [0,2.5,5,7.5,10]，第 3 个是"点数"，含 stop
np.empty((2, 3))             # 不初始化，速度快但值是内存残留
np.random.rand(3, 3)         # 均匀分布随机数，shape 直接传数字不用元组
```

**关键区分：**
- `arange(start, stop, step)`：**"a for step"**，第 3 个是步长
- `linspace(start, stop, N)`：**"l for length"**，第 3 个是点数
- N 个点 = N-1 段。想把 [0,10] 平均分成 2 段，要写 `linspace(0,10,3)`

### 2. 数组属性

| 属性 | 含义 |
|---|---|
| `ndim` | 维度数（几维数组） |
| `shape` | 每个维度的元素个数（元组） |
| `size` | 元素总数 = shape 各维度相乘 |
| `dtype` | 元素类型（int64 / float64 …） |
| `itemsize` | 每个元素占多少字节 |

**shape 读法：从左到右 = 从最外层到最里层。** 例如 `(2, 3, 4)` = 2 个 3×4 的矩阵摞在一起。

**一维和二维区别：**
- `np.array([1,2,3])` → shape `(3,)`  一维
- `np.array([[1,2,3])` → shape `(1, 3)` 二维
- 神经网络喂样本要 batch 维，所以经常需要 `(3,)` → `(1, 3)`

**升维 3 种方法：**
```python
a.reshape(1, 3)      # 最通用
a[np.newaxis, :]     # 高频，用于广播
a[None, :]           # None 是 np.newaxis 的别名
```

### 3. 索引与切片

1. 一维 a[2:5]不含stop。a[::-1]反转。a[::2 ]步长。
2. 二维 b[行,列]，逗号语法。
3. 花式索引b[[0,2]]选多行。

**花式索引 + 布尔索引：**
```python
b = np.arange(12).reshape(3, 4)

# C-1 花式索引（用数组当索引）
b[[0, 2]]                # 取第 0 行和第 2 行（跳过第 1 行）
b[:, [0, 3]]             # 取第 0 列和第 3 列
b[[0, 1, 2], [1, 2, 3]]  # 取 (0,1) (1,2) (2,3) 三个点 → [1, 6, 11]
# 注意：最后一个是按位配对，不是"前 3 行 × 后 3 列" 3×3 矩阵

# C-2 布尔索引（用条件当索引）
b > 5              # 输出一个和 b 同 shape 的布尔矩阵
b[b > 5]           # 取出所有大于 5 的元素 → 一维数组
b[b % 2 == 0]      # 取出所有偶数
```

### 4. 形状变换

- reshape(3, 4) / reshape(3, -1) （-1 让 NumPy 自动算）
- .T 转置、.ravel() 摊平
- 升维 3 种：reshape(1,3) / [np.newaxis, :] / [None, :]

### 5. 广播（Broadcasting）— 三条规则

1. 补 1：维度少的左边补 1，补齐到相同 ndim
2. 每一维要么相等，要么其中一个是 1，否则报错
3. 大小为 1 的维度会沿着那一维复制成对方的大小

**用 `b + c` 举例：**
- b.shape = (3, 1)，c.shape = (3,)
- 步骤 1：c 维度少，左边补 1 → 变成 (1, 3)
- 步骤 2：对比 (3, 1) 和 (1, 3)，每一维要么相等要么有 1 ✅
- 步骤 3：b 沿着列复制成 (3, 3)，c 沿着行复制成 (3, 3)
- 结果 shape (3, 3)

## 踩的坑

1. **`np.ones(3, 5)` ❌ vs `np.ones((3, 5))` ✅**：多维 shape 必须用元组括起来，否则第二个参数会被当成 dtype 报错。一维可以直接写数字 `np.ones(5)`。
2. **`int64` 和 `float64` 字节长度一样（都是 8 字节）**，"类型提升"不是按长度选，而是按**能不能装下不丢信息**——float 能装 int（存成 1.0），int 不能装 float（会丢小数），所以混合数组选 float。规则叫 **type promotion（就高不就低）**。
3. **`arange` 第 3 个是步长，`linspace` 第 3 个是点数**——Day 1 已经踩过一次，今天正式厘清。
4. **`==` 不能比较浮点数**：`0.3 == 3 * 0.1` 是 `False`（浮点精度 0.30000000000000004）。用 `np.isclose(a, b)` 或 `abs(a-b) < 1e-9`。
5. **`np.nan == np.nan` 是 `False`**（IEEE 754 规定 nan 和任何东西比较都是 False，包括自己）。判断 nan 用 `np.isnan(x)`。
6. **numpy-100 Q14 边界赋值**：`a[1:-1, 1:-1] = 0` 比 `a[1:4, 1:4] = 0` 更通用（任何 shape 都能用）。
7. **`arrange` 是英语单词"安排"，NumPy 是 `arange`（一个 r）**，别拼错。
